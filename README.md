# 🌱 GREEN CIRCUIT – Smart Farming System

GREEN CIRCUIT is an AI-powered, offline smart farming solution designed to help farmers make data-driven decisions without relying on continuous internet connectivity. The system uses low-cost IoT sensors and edge AI to monitor farm conditions, optimize irrigation, and promote sustainable agriculture.

---

## 🚜 Problem Statement
Traditional farming relies on manual monitoring and guess-based decisions, leading to water wastage, soil degradation, delayed crop stress detection, and increased operational costs. Most existing smart farming solutions are expensive and internet-dependent, making them inaccessible for small and marginal farmers.

---

## 💡 Solution Overview
GREEN CIRCUIT uses an ESP32-based edge controller connected to soil moisture, temperature, humidity, and rain sensors. The system analyzes real-time data locally using edge AI to predict irrigation needs, detect abnormal farm conditions, and automatically control water flow. It works completely offline with a one-time installation, making it ideal for rural and low-connectivity regions.

---

## 🧠 Key Features
- Fully offline operation (edge processing)
- AI-driven irrigation optimization
- Real-time soil and environmental monitoring
- Automatic pump/irrigation control
- Low-cost, scalable, and farmer-friendly design
- Supports sustainable farming practices

---

## 🛠️ Hardware Components
- ESP32 Development Board
- Soil Moisture Sensor
- DHT11 Temperature & Humidity Sensor
- Rain Sensor Module
- 0.96" OLED Display (I2C)
- Relay Module / Motor Driver
- Submersible Water Pump
- Power Supply (Battery / Solar – optional)
